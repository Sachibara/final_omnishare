01 Capstone Project

Pyrewall — Next Generation Firewall

A Windows-focused firewall and network monitoring desktop application written in Python with PyQt6. The project combines traffic control, device visibility, domain filtering, rule management, threat views, history, and local persistence.

  • Background firewall controller designed to avoid blocking the Qt user interface.
  • Domain and IP filtering with DNS-related handling and firewall rule integration.
  • Connected-device detection and block/unblock controls using ARP and Windows networking tools.
  • SQLite-backed runtime data with packaging-aware database paths for desktop deployment.
  • Tabbed dashboard for overview, network control, threats, rules, history, settings, and administration.

02 Web Prototype

OmniShare

A responsive secure-file-sharing interface prototype built as a single-page web application. It supports user flows for file selection, upload simulation, generated file IDs, expiration settings, download lookup, and upload/download history.

  • Drag-and-drop and browse-based file selection.
  • Configurable file expiration states and file information lookup.
  • Client-side account, history, and state persistence using localStorage.
  • Responsive interface with modal authentication flows and activity statistics.
